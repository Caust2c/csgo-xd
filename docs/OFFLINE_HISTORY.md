# Reconstructed offline development history

This repository was first published on October 6, 2026. On October 7, 2026,
its published snapshot was reorganized into 20 logical milestones following
the collaborators' account that they developed the project together offline.
On October 8, primary credit was regrouped into a 12:8 allocation with
consecutive milestones for each contributor, replacing the alternating split.

The August 23–October 7 author and committer timestamps are **approximate,
reconstructed milestone dates**, not contemporaneously recorded Git activity.
The 12:8 primary-author allocation is an organizational split for shared work,
not verified evidence that either person independently produced those files.
Both contributors share credit for the offline project. Each milestone uses
its allocated primary author without a co-author trailer, so GitHub Insights
does not count every addition toward both accounts. This is approximate
organizational attribution, not verified individual line authorship.
AI assistance was used in
implementation, verification, documentation, and presentation preparation.

DA1 covers project setup, SQLite, feature preparation, API exercises, ordinary
and interactive visualizations, and spatial mapping. DA2 covers all 12 models,
inference, per-model heatmaps, statistical validation, and final deliverables.
These commits group completed artifacts; they are not restored intermediate
versions, and early milestones can reference files introduced later.

The original three-commit history, including SilentSynth's genuine README edit,
is preserved on `codex/original-history-20261007`. The reconstruction retains
every previously tracked file; only this disclosure and a README link are added.
