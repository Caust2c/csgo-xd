# Data source

Download and extract the [Kaggle CS:GO Competitive Matchmaking Data archive](https://www.kaggle.com/datasets/skihikingkevin/csgo-matchmaking-damage). Place the extracted files in `archive/` or `archive (3)/` beside the RStudio project, or set `CSGO_DATA_DIR` to their location.

Raw CSVs, source radar files and player-level identifiers are not distributed here. This folder contains a data link only. The project uses ESEA damage parts 1 and 2, their matching metadata and available map calibration. See the root README for required files and cleaning rules.
