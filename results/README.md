# Production result snapshot

These files capture the verified production run used in the research paper. They are separate from `output/`, which is regenerated by the R workflow.

Open `index.html` locally after downloading or cloning the repository. GitHub does not execute HTML galleries or Plotly charts in its file preview. Keep the three interactive chart asset folders beside their HTML files.

The snapshot contains model metrics, uncertainty estimates, feature selection and importance tables, import counts, settings and package versions, 224 spatial images with aggregate grids, 12 static EDA charts and three interactive charts. Raw event CSVs, row-level predictions, match split identifiers, fitted model objects and the SQLite database are excluded. The manifest's database path is normalized to the repository-relative local destination.

For execution, interpretation, assumptions and future work, see the [project guide](../README.md). Radar backgrounds in derived images originate from the Kaggle archive; this repository does not grant rights to those source assets.
